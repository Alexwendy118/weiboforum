# 微波论坛（Microwave Forum）v1.1

一个使用 **纯 HTML + CSS + JavaScript** 编写的轻量微社区单页应用，零框架、零构建、零外部依赖。所有内容保存在浏览器 `localStorage`，刷新或重开浏览器后依然存在。

站名与文案均为"微波论坛"，不包含任何第三方平台的名称与品牌元素。

## 界面结构

- **顶部品牌栏**：站名标识 + 当前身份（可修改昵称）
- **Hero 横幅**：标题、通栏搜索条（输入框 + 橙色搜索按钮）、本地数据统计（动态数 / 点赞数 / 板块数）
- **左栏**：功能导航（实时动态 / 热门榜 / 我赞过的 / 我的动态，带数量角标）与板块列表（全部 / 生活 / 科技 / 心情 / 随笔）
- **中栏**：发布卡（含板块选择）、视图 Tab（实时 / 热门 / 我的）、结果统计与动态流
- **右栏**：微波热榜（按点赞排序、前三名配色、换一换、查看更多）、本地版推广卡与小提示

## 功能

- 发布文字动态（上限 140 字，实时字数提示，超限禁用发布并抖动提醒），发布时选择板块
- 时间线按发布时间倒序展示，相对时间显示（刚刚 / N 分钟前 / N 小时前 / N 天前 / 具体日期）
- 视图切换：实时 / 热门（按点赞排序）/ 我的 / 我赞过的；板块筛选可与视图叠加
- 点赞 / 取消点赞，数量与状态持久化，并实时反映到热榜与统计
- 删除自己发布的动态（仅本人可见入口，二次确认 + 淡出动画）
- 关键词搜索（匹配正文、昵称或板块，大小写不敏感），支持输入即筛与回车/点击搜索
- 热榜：按点赞排名，支持换一换、查看更多/收起，点击条目自动清空筛选并滚动定位、高亮对应动态
- 本地昵称修改，修改后同步更新自己已发布的内容
- 空状态引导、Toast 提示、暗色模式与减少动效适配
- 本地存储不可用（隐私模式 / 配额满）时自动降级为内存态并给出提示

## 运行

方式一：直接双击 `index.html`，用浏览器打开。

方式二：启动一个静态服务器（推荐，避免个别浏览器的本地文件限制）：

```bash
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 数据存储

| Key | 说明 |
| --- | --- |
| `mwb.posts.v1` | 全部动态数组，元素含 `id / authorId / author / topic / content / createdAt / likes / likedByMe` |
| `mwb.user.v1` | 当前本地身份（id 与昵称） |

旧版本数据无 `topic` 字段时会自动回落为「随笔」，升级无需迁移。清空数据：浏览器开发者工具 → Application → Local Storage → 删除上述两个 key，刷新后恢复初始示例内容。

## 响应式

| 视口 | 布局 |
| --- | --- |
| > 1180px | 左栏 + 中栏 + 右栏三栏并排 |
| 900 ~ 1180px | 左栏折叠为横向胶囊按钮条，中栏 + 右栏两栏 |
| < 900px | 单栏纵向：导航胶囊条 → 发布与动态流 → 热榜与推广卡 |
| < 640px | 均为单列，按钮与输入框适配触控尺寸，无横向滚动 |

## 说明

- 渲染用户文本统一使用 `textContent`，从根本上避免 XSS。
- 首次访问会写入 3 条示例动态（`seed-*`），可自由删除。
- 本项目仅用于本地演示，没有后端与账号体系，数据不会离开本机浏览器。
